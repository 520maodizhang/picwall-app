# 照片墙 - 打包部署说明

## 文件清单
- `v87.html` - 主应用（单文件，含全部 CSS/JS）
- `manifest.json` - PWA 清单
- `sw.js` - Service Worker（离线缓存）
- `app-icon.svg` - 应用图标
- `capacitor.config.json` - Capacitor 原生壳配置

## 1. PWA（渐进式 Web 应用）
- 已内置 manifest + Service Worker
- 用 HTTPS 访问即可"添加到主屏幕"，全屏离线使用
- Chrome / Safari / Edge 均支持

## 2. Android APK（通过 Capacitor）
```bash
npm install -g @capacitor/cli @capacitor/core
npm install @capacitor/android

mkdir -p www
cp v87.html manifest.json sw.js app-icon.svg www/

npx cap add android
npx cap sync

cd android && ./gradlew assembleDebug
# APK 在 android/app/build/outputs/apk/debug/app-debug.apk
```

## 3. iOS IPA（通过 Capacitor）
```bash
npm install @capacitor/ios
npx cap add ios
npx cap sync
# 用 Xcode 打开 ios/App，Archive → Export IPA
```

## 4. 华为云 OBS 静态网站托管
```bash
obsutil mb obs://picwall-app -c public-read
obsutil cp v87.html obs://picwall-app/
obsutil cp manifest.json obs://picwall-app/
obsutil cp sw.js obs://picwall-app/
obsutil cp app-icon.svg obs://picwall-app/
obsutil website obs://picwall-app -i v87.html -e 404.html
```

## 5. 桌面应用（Capacitor + Electron）
```bash
npm install @capacitor-community/electron
npx cap add @capacitor-community/electron
npx cap sync @capacitor-community/electron
cd electron && npm run build
```
